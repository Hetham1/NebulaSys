# Code of Conduct

NebulaSys contributors are expected to keep discussion respectful, technical, and constructive.

## Expected Behavior

- Assume good intent while still reviewing code rigorously.
- Keep feedback specific and actionable.
- Respect maintainers' decisions about safety-sensitive package operations.
- Avoid harassment, personal attacks, and discriminatory language.

## Unacceptable Behavior

- Threats, harassment, or abusive comments.
- Publishing private information.
- Pushing users toward unsafe system changes without clear warnings.
- Repeatedly derailing technical discussion after maintainers ask to refocus.

## Enforcement

Maintainers may edit or remove comments, close issues, reject pull requests, or block contributors who violate this code of conduct.

Report concerns to the repository maintainer.
